

## Итоговые результаты сессионного проекта

Операционная система: RED ОС 8.0.3 Standard Desktop (aarch64).

Номер студента: М265325.

### Выполненные настройки

- Hostname: `mephi-2026.domain.local`

- Сетевой интерфейс получает IPv4 через DHCP.

- Установлены nginx, libcap-ng-utils и tcpdump.

- Дополнительный диск: `/dev/sdb1`, ext4, метка `MEPHI\_WEB`.

- Постоянная точка монтирования: `/mephi-web`.

- Nginx включён в автозагрузку и обслуживает страницу из `/mephi-web`.

- SELinux работает в режиме `Enforcing`.

- Для веб-каталога настроены постоянные SELinux-контексты.

- Разработчики: `user1` (5501), `user2` (5502), `user3` (5503).

- Группа `curators`: GID 4444.

- DAC/ACL: разработчики совместно изменяют файлы, кураторы читают без права записи, остальные пользователи не имеют доступа.

- Для tcpdump назначена файловая привилегия `cap\_net\_raw=ep`.

- PAM ограничивает локальный вход пользователей `curator1` и `curator2`.

- Минимальная длина новых паролей: 12 символов.

- Максимальный срок действия пароля: 90 дней.

### Функциональные проверки

- DAC/ACL: реальные операции пользователей выполнены успешно.

- TCPdump: обычный пользователь `user1` успешно захватил сетевой пакет.

- PAM: отказ локального входа `curator1` подтверждён журналом.

- HTTP: `curl http://localhost/` возвращает `Hello from Student: М265325`.

- После перезагрузки подтверждены монтирование диска, работа nginx, SELinux Enforcing, файловые Capabilities и настройки пользователей.

- Итоговый скрипт проверки сообщает PASS по основным системным параметрам.

### Доказательства
